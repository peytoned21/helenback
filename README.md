# Helenback

The site for Helenback, an annual friends' trip to the North Georgia mountains, running since 2008.
This year's page covers Helenback XIV (Nov 5–8, 2026), and the archive covers every edition since 2008.

Static site: `index.html`, `photos/`, an offline service worker (`sw.js`), and a calendar file.
Weather comes live from the National Weather Service and the Georgia score from ESPN's public scoreboard.
